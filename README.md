# Ayush Roy — Portfolio Website

A static portfolio website for Ayush Roy, Graphic & Communication Design student.

## Project structure

```text
.
├── index.html                 # Home page
├── pages/                     # Secondary pages
│   ├── about.html
│   ├── portfolio.html
│   ├── skills.html
│   ├── contact.html
│   ├── resume.html
│   └── games/                 # Individual portfolio project pages
├── assets/
│   ├── images/
│   │   ├── ayush.jpg          # Profile photo
│   │   └── placeholders/      # Placeholder logo and project artwork
│   └── resume/
│       └── Ayush-Roy-Resume.pdf
├── css/                       # Stylesheets
└── js/                        # JavaScript
```

## Run locally

Open `index.html` in a browser. No build step is required for the static site.

## Notes

- Keep the relative paths intact when moving files.
- Replace placeholder SVGs when final project artwork and branding are ready.
- The original CV PDF is stored in `assets/resume/`.
